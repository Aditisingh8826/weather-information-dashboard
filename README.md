
# Weather Information Dashboard

A web-based weather dashboard that allows users to search for a city and view its current weather conditions.

## Features

- Search weather information by city name.
- Display current temperature.
- Show humidity and wind speed.
- Display feels-like temperature.
- Show weather conditions with corresponding icons.
- Input validation and error handling.
- Loading indicator while fetching weather information.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Geocoding API
- Open-Meteo Forecast API

## APIs Used

- **Open-Meteo Geocoding API:** Retrieves geographical coordinates based on the entered city name.
- **Open-Meteo Forecast API:** Retrieves current weather information using geographical coordinates.

## How to Run the Project

1. Clone or download this repository.
2. Extract the downloaded ZIP file.
3. Open the project folder in Visual Studio Code.
4. Open `index.html` in your browser.
5. Enter a city name and search for its weather information.

You can also use the Live Server extension in Visual Studio Code.

An active internet connection is required for API requests.
